# design-learning-log

我想學：培養審美與視覺判斷力，能看出一個作品為什麼好看，並說明它在色彩、字體、排版、留白和構圖上的特色。

我以前卡在：我常常只能感覺「這張比較好看」，但說不清楚具體原因，也不知道應該從哪些角度分析作品。

我現在的程度，以及我怎麼測的：目前能分辨自己喜歡或不喜歡的作品，但還不能穩定地說出原因。先觀察設計作品並寫下至少2個理由，作為初始測驗。

5 週後我要做到：完成至少 25 次審美觀察，能從色彩、字體、排版、留白和構圖等角度分析作品，並對自己的設計提出具體修改建議。

我練習的場景、時間和每週次數：在做作業、找設計參考或課前準備時練習。每週練習 4 次，每次約 20 至 30 分鐘。

那個時候我有空的感官：主要使用視覺和閱讀文字，觀看設計作品、比較版面差異，並用文字記錄自己的觀察與判斷。

我的產品會怎麼幫我：製作一個審美練習網頁，每次提供兩張設計作品，讓我選出比較喜歡的一張並寫下理由，再記錄我是從色彩、字體、排版、留白或構圖哪個角度做判斷，幫助我逐漸建立自己的審美分析方法。
